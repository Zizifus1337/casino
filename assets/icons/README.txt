ИКОНКИ ЗДАНИЙ, УЛУЧШЕНИЙ И ДОСТИЖЕНИЙ
=====================================
Сейчас вместо картинок в игре эмодзи. Чтобы заменить иконку своей:
 1. Нарисуйте PNG 256x256 с прозрачным фоном (рисунок по центру, поля ~10%).
 2. Назовите файл по id иконки и положите СЮДА: assets/icons/<id>.png   (например basement.png).
 3. Откройте assets_check.html в браузере: найденные файлы будут отмечены, а внизу появится
    готовый текст для assets/icons/manifest.js. Скопируйте его в manifest.js.
 4. Обновите игру (Ctrl+F5).
Полный список id и где какая иконка видна: ИНСТРУКЦИЯ_ПО_ЗАГЛУШКАМ.md (раздел 4).
